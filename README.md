# A Little Something for You

A self-contained, GitHub Pages-ready Valentine website. It uses only HTML, CSS, and JavaScript—no build step or server is needed.

## Personalize it

Open `index.html` and replace the two paragraphs inside the `letter-card` section with your own message. You can also change the browser title and each question/button label there.

## Publish on GitHub Pages

1. Create a new GitHub repository and upload the contents of this folder (so `index.html` is at the repository root).
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder, then save.
5. After GitHub finishes deploying, open the Pages URL it shows—usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

You can test it locally first by opening `index.html` in any modern browser.
